# 📊 Superstore Data Analysis

## 📌 Overview
This project performs end-to-end data analysis on the Superstore dataset to extract meaningful business insights. It involves data cleaning, exploratory data analysis (EDA), and visualization to understand sales, profit, and discount patterns.

## 🛠️ Technologies Used
Python, Pandas, NumPy, Matplotlib, Seaborn, SQL

## 🔍 Analysis Performed
The dataset is cleaned and preprocessed to handle missing values and duplicates. Exploratory data analysis is conducted to evaluate sales and profit performance across different categories, regions, and segments. The impact of discounts on profitability is also analyzed.

## 📈 Visualizations
Various visualizations are created to highlight trends and patterns, including category-wise sales, region-wise profit, discount vs profit relationships, and top-performing sub-categories.

## 💡 Key Insights
The analysis reveals that higher discounts often reduce profit margins, certain sub-categories contribute to losses, and performance varies significantly across regions and customer segments.

## 🚀 Usage
Install required libraries using pip and run the notebooks to reproduce the analysis and visualizations.

## 📊 Dataset
Superstore dataset (Kaggle)
